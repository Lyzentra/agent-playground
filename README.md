# agent-playground
Playground for the Lyzentra AI agent: label an issue ai-agent and the agent opens a pull request.

## API Endpoints

### GET /hello
Returns a greeting message.

**Response:**
```json
{
  "message": "Hello, world!"
}
```

**Status Code:** 200

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Start the server:
   ```
   npm start
   ```

3. The server will start on port 3000 (or specified PORT environment variable)
